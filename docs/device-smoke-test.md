# iPhone 실기기 스모크 테스트

자동 테스트(Vitest, Playwright/Chromium)로는 **iOS Safari의 음성·오디오 동작을 검증할 수 없습니다.**
배포 후 아래 항목을 iPhone에서 직접 확인하고 결과를 기록하세요.

| 환경                     | 값  |
| ------------------------ | --- |
| 기기 / iOS 버전          |     |
| 테스트 날짜              |     |
| 앱 버전 (설정 화면 하단) |     |

## A. Safari 탭

| #   | 절차                           | 기대 결과                                                    | 결과 |
| --- | ------------------------------ | ------------------------------------------------------------ | ---- |
| A1  | 앱 URL 열기                    | 홈 화면, 설치 안내 배너 표시                                 |      |
| A2  | 학습 시작 → 🔊 원문 듣기       | 영어 음성 재생 (무음 스위치 ON/OFF 둘 다 확인)               |      |
| A3  | 속도 0.7× 선택 후 듣기         | 눈에 띄게 느려짐                                             |      |
| A4  | 🎤 따라 말하기 (첫 사용)       | 마이크/음성인식 권한 요청 → 허용                             |      |
| A5  | 문장을 말함                    | 말이 끝나면 자동 종료, 정확도·틀린 단어 표시                 |      |
| A6  | 일부러 한 단어 틀리게 말함     | 해당 단어가 빨간 물결 밑줄 + "→ 들린 말"                     |      |
| A7  | 🔁 구간 버튼 → 듣기 → 말하기   | 구간만 재생·채점, "다음 복습" 문구 없음                      |      |
| A8  | 인식 직후 🔊 원문 듣기         | **소리가 스피커로 정상 볼륨** (수화기로 작게 나오면 R7 이슈) |      |
| A9  | 🎤 누르고 10초 이상 침묵       | "음성이 들리지 않았어요" 안내                                |      |
| A10 | 설정 › Siri › 받아쓰기 끄고 A5 | 권한 오류 안내 (자가채점 전환 가능)                          |      |

## B. 홈 화면 앱 (공유 → 홈 화면에 추가)

| #   | 절차                    | 기대 결과                                                            | 결과 |
| --- | ----------------------- | -------------------------------------------------------------------- | ---- |
| B1  | 홈 화면 아이콘으로 실행 | 주소창 없는 전체 화면, 상단 안전영역 침범 없음                       |      |
| B2  | A2~A6 반복              | Safari 탭과 동일하게 동작 (**인식 실패 시 자가채점으로 전환되는지**) |      |
| B3  | 앱 종료 후 재실행       | 오늘 통계·복습 일정 유지                                             |      |
| B4  | 비행기 모드 → 앱 실행   | 앱이 열림, 원문 듣기 동작                                            |      |
| B5  | 비행기 모드 → 🎤        | 녹음 → 내 목소리 듣기 → 단어 탭 → 채점 완료                          |      |
| B6  | 화면 잠금 후 복귀       | 재생 중이던 음성 정지, 오류 없음                                     |      |

## C. 접근성

| #   | 절차                                  | 기대 결과                                 | 결과 |
| --- | ------------------------------------- | ----------------------------------------- | ---- |
| C1  | VoiceOver 켜고 홈 탐색                | 통계·버튼 이름이 한국어로 읽힘            |      |
| C2  | 연습 → 채점                           | "정확도 N퍼센트, 틀린 단어 N개" 자동 낭독 |      |
| C3  | 설정 › 손쉬운 사용 › 텍스트 크기 최대 | 레이아웃 깨짐·가로 스크롤 없음            |      |
| C4  | 다크 모드 전환                        | 모든 화면 대비 충분                       |      |

## D. 데이터

| #   | 절차                             | 기대 결과                   | 결과 |
| --- | -------------------------------- | --------------------------- | ---- |
| D1  | 설정 › 백업 내보내기             | JSON 파일 저장 (파일 앱)    |      |
